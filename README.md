# Assignment 2 - Functionality in Portfolio Website

## 👤 Author

**Shlok Gupta**

## 📌 Description

This project is a personal portfolio website created using **HTML, CSS, and basic JavaScript** as part of **Assignment 2**.
It showcases personal information, hobbies, and projects in a clean and responsive layout.

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Basic DOM Manipulation)

---

## 📂 Project Structure

* `index.html` → Main structure of the website
* `style.css` → Styling and responsive design

---

## 🌟 Features

### 🔹 General

* Clean and modern UI
* Responsive design for mobile and desktop
* Navigation bar for smooth section access

### 🔹 Home Section

* Displays hobbies
* Dynamic feature to **add new hobbies**
* Each hobby has a **delete button**

### 🔹 Projects Section

* Card-based layout
* Displays sample project titles

### 🔹 Contact Section

* Simple contact form
* Shows alert on submission

### 🔹 Footer

* Displays **real-time date and time**
* Links to LinkedIn and GitHub

---

## ⚙️ JavaScript Functionality

* Add new hobbies dynamically
* Delete existing hobbies
* Form submission alert
* Live date and time display

---

## 🚀 How to Run

1. Download or clone the repository
2. Make sure both files are in the same folder:

   * `index.html`
   * `style.css`
3. Open `index.html` in any web browser

---

## 📱 Responsiveness

The website adapts to different screen sizes using CSS media queries, ensuring usability on mobile devices.

---

* This is a beginner-level project created for learning purposes
